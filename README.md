## 🛠️ Tech Stack & Architecture
- **Frontend Core:** Semantic HTML5, Custom Vanilla CSS3 (Design Tokens, Fluid Typography, Micro-animations)
- **Interactivity:** Vanilla JavaScript (Smooth Scroll, Team Carousel, Drag-and-Scroll Rail, Contact Action Sheet Modal)
